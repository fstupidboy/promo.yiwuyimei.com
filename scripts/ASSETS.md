## Display Stand Assets Helper

This repo includes a helper to source free commercial-use images for various display stand categories. Prefer product-style photos with minimal background clutter and no visible brand logos.

### Categories
- Roll-up banner stand (易拉宝 / roll up banner)
- X banner stand (X展架)
- Fabric pop-up display / pop up backdrop (拉网展架)
- Acrylic display stand / holder (亚克力展示架)
- Wooden display stand / shelf (木质展示架)
- Metal display rack / stand (金属展示架)
- Cardboard display stand / corrugated POS (纸质展示架)
- PVC foam board stand / KT board (PVC/KT板展架)
- Gridwall display / wire grid (网片展示架)
- Tabletop display stand (桌面展示架)
- Brochure holder / literature rack (资料架)
- Rotating display stand (旋转展示架)

### Automated Fetch (Pexels/Pixabay APIs)
Use the Python helper to fetch 5–8 images per category and optionally download them into `static/images/displays/<category>/`.

1) Install dependency:
```bash
pip install requests
```

2) Export API keys (sign up free):
```bash
export PEXELS_API_KEY="<your-pexels-key>"
export PIXABAY_API_KEY="<your-pixabay-key>"
```

3) Generate JSON manifest (8 per category):
```bash
python3 scripts/fetch_display_assets.py --per-category 8 --out-json scripts/display_assets.json
```

4) Also download images into Hugo static folder:
```bash
python3 scripts/fetch_display_assets.py --per-category 8 --download --out-dir static/images/displays
```

Notes:
- License: Pexels/Unsplash/Pixabay allow free commercial use; always double-check per image page.
- Prefer neutral shots with no visible logos; avoid images centered on people if possible.
- After download, assets will be available at `/images/displays/<category>/...` in the site.
